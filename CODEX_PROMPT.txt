Ты работаешь с проектом Google Apps Script для системы документооборота по объектам.

К задаче приложены:

- `SystemCore.gs`
- `Code.gs`
- `OperatorSidebar.html`
- `01_SHEET_STRUCTURE.md`
- `02_CREATION_MODULE_SPEC.md`
- `03_ACCEPTANCE_TESTS.md`
- `04_ARCHITECTURE_GUARD.md`

## Задача

Реализуй новый модуль массового создания недостающих документов по всем корректным объектам.

Создай новый файл:

`CreateObjectDocuments.gs`

Главная публичная функция для кнопки:

```javascript
createMissingDocumentsForAllObjects
```

Пользователь просто нажимает кнопку `Создать документы`. Выделение строки не используется. Один запуск обрабатывает весь лист `Объекты`.

## Перед реализацией

1. Изучи все приложенные файлы.
2. Проверь реальные имена констант, ключей конфигурации и вспомогательных функций в `SystemCore.gs`.
3. Используй существующее ядро как источник истины.
4. Не создавай второй независимый набор заголовков и настроек.
5. Сопоставь спецификацию с фактическими функциями проекта.
6. Если требуется изменение архитектуры или существующих файлов, не вноси его автоматически. Опиши проблему и запроси согласование.

## Обязательная логика

- Читать все объекты с `Объекты`.
- Пропускать некорректные объекты, обрабатывая остальные.
- Читать комплект из `Справочник документов` по `Автоматически`.
- Критические ошибки справочника останавливают запуск до записи.
- Проверять существование по `ID объекта + ID типа документа`.
- Создавать только недостающие сочетания.
- Не менять существующие документы.
- Учитывать любую существующую строку с полным ключом независимо от статусов.
- Формировать `DOC-{ID объекта}-{порядковый номер}`.
- Использовать максимальный существующий номер внутри объекта + 1.
- Выполнять проверку и создание под общей блокировкой.
- Записывать строки пакетно.
- После успешной записи вести обе истории.
- Показывать итоговый отчёт.
- Реализовать все 15 приёмочных сценариев.

## Технические ограничения

- Apps Script V8.
- Не использовать буквы столбцов.
- Не использовать фиксированные номера столбцов вне конфигурации.
- Не использовать `appendRow` в циклах.
- Читать через `getValues` / `getDisplayValues`.
- Записывать через пакетный `setValues`.
- Использовать функции и конфигурацию `SystemCore.gs`.
- В начале проверять структуру системы.
- Не добавлять формулы в факты.
- Не подключать внешние сервисы и API.
- Не менять `onOpen`.
- Не менять карточку операциониста.
- Не исправлять существующие данные автоматически.
- Не менять архитектуру без согласования.

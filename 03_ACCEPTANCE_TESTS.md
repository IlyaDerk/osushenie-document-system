# 15 сценариев приёмочного тестирования

## 1. Первый запуск по новому объекту

Дано: корректный объект, 8 автоматических типов, фактов нет.

Ожидается:

- создаётся 8 строк;
- порядок совпадает со справочником;
- ID: `DOC-{ID объекта}-0001` ... `0008`;
- поля заполнены по спецификации;
- созданы истории.

## 2. Повторный запуск

Дано: весь комплект существует.

Ожидается:

- создано 0 строк;
- факты не меняются;
- статус `Без изменений`.

## 3. Один недостающий документ

Дано: требуется 8, существует 7, отсутствует `КС-3`.

Ожидается:

- создаётся только `КС-3`;
- существующие строки не меняются;
- ID продолжает последовательность.

## 4. Новый тип в справочнике

Дано: комплект создан, затем добавлен новый автоматический тип.

Ожидается:

- новый тип создаётся по всем корректным объектам, где его нет;
- старые документы не дублируются.

## 5. Неполный объект

Дано: отсутствует обязательное поле, например `Номер договора`.

Ожидается:

- объект пропускается;
- остальные обрабатываются;
- указаны строка, ID и причина.

## 6. Пустая фактическая дата окончания

Ожидается:

- объект корректен;
- документы создаются;
- фактическая дата остаётся пустой.

## 7. Ошибка дат

Проверить:

1. значение не является датой;
2. плановое окончание раньше начала.

Ожидается:

- объект пропускается;
- причина указана;
- остальные обрабатываются.

## 8. Повторяющийся ID объекта

Дано: один ID встречается в двух строках.

Ожидается:

- пропускаются все строки с этим ID;
- документы не создаются;
- перечислены конфликтующие строки.

## 9. Неполное автоматическое правило

Дано: у автоматического правила нет ID или названия.

Ожидается:

- запуск останавливается до записи;
- указаны лист, строка и поле;
- новых документов нет.

## 10. Дубли правил

Проверить:

1. один ID связан с разными названиями;
2. одно название связано с разными ID.

Ожидается:

- запуск останавливается;
- документы не создаются;
- конфликты перечислены.

## 11. Дубль сочетания объект/тип

Дано: уже есть две строки с одинаковым ключом.

Ожидается:

- третья не создаётся;
- существующие не меняются;
- дубль отражён в предупреждениях.

## 12. Неполная строка фактов

Дано: нет `ID объекта` или `ID типа документа`.

Ожидается:

- строка не участвует в комплектности;
- корректный документ может создаться;
- строка отражена как предупреждение.

## 13. Продолжение нумерации

Дано:

- `DOC-2605-0001`
- `DOC-2605-0002`
- `DOC-2605-0005`

Ожидается: следующий ID `DOC-2605-0006`.

## 14. Одновременный запуск

Дано: два пользователя запускают почти одновременно.

Ожидается:

- общая блокировка;
- последовательное выполнение;
- нет дублей сочетаний и ID.

## 15. Истории

После запуска с созданием:

В `История операций` — одна строка с ID, временем, email, источником, типом, статусом, счётчиками, временем выполнения и комментарием.

В `История изменений` — связанные строки по заполненным полям новых документов с тем же `ID операции`.

# Общий критерий приёмки

- все 15 сценариев пройдены;
- повторный запуск не создаёт дубли;
- ошибка одного объекта не блокирует остальные;
- критическая ошибка не допускает создания;
- код не зависит от букв и порядка столбцов;
- архитектура не изменена.
